# Плагин «Веб-окно» для Redmine

Плагин добавляет в Redmine возможность вставить **окно (iframe) с любой
веб-страницей** — двумя способами:

1. **Блок «Веб-страница (окно)» в дашбордах Additionals** — блок добавляется
   из списка блоков, и в его настройках остаётся вписать только ссылку
   (и при желании высоту). Нужен актуальный Additionals (4.x, Redmine 7).
2. **Wiki-макрос `{{web_window}}`** — работает без зависимостей: в блоке
   «Текст» дашбордов Additionals (любой версии), на вики-страницах и в тексте
   приветствия.

## Блок «Веб-страница (окно)» в дашбордах Additionals

1. Открыть главную страницу (или обзор проекта) → «Настроить» дашборда →
   «Добавить блок» → **«Веб-страница (окно)»**.
2. У блока сразу откроется форма настроек — вписать **адрес** страницы,
   при желании задать заголовок и высоту окна (100–3000 px, по умолчанию 485).
3. Сохранить.

Блок можно добавлять многократно (до 10 окон в дашборде), каждый со своей
ссылкой. Если ссылку не задать, блок сам считается ненастроенным и
предлагает открыть настройки.

**Поддерживаемые версии Additionals** (плагин определяет вариант автоматически):

- **4.7 и новее** — классовая система блоков: блок без ссылки сразу
  открывает форму настроек, у высоты действует ограничение 100–3000;
- **4.0–4.6** — легаси-механизм: тот же блок и те же настройки; если ссылку
  не задать, блок показывает подсказку (откройте настройки блока вручную).

## Установка

1. Скопировать папку `redmine_web_window` целиком в папку `plugins`
   установленного Redmine, чтобы получился путь
   `<redmine>/plugins/redmine_web_window/init.rb`. Через git — одной командой
   (из корня Redmine):

   ```
   git clone https://github.com/kirilljan985-debug/redmine_iframe plugins/redmine_web_window
   ```

2. Перезапустить Redmine (Bitnami: Stop/Start в менеджере; Linux:
   `systemctl restart redmine`). Gem-ы и миграции не нужны.

## Макрос {{web_window}} — окно в блоке «Текст» и не только

1. Открыть главную страницу (или обзор проекта) → «Настроить» дашборда →
   «Добавить блок» → выбрать блок **«Текст»**.
2. В текст блока вписать макрос с адресом страницы, например:

   ```
   {{web_window(http://192.168.1.50:8000)}}
   ```

3. Сохранить дашборд — в блоке появится окно с этой страницей.
   Также макрос работает на вики-страницах и в тексте приветствия.

Параметры макроса:

| Параметр | Пример | Описание |
|----------|--------|----------|
| адрес    | `{{web_window(http://192.168.1.50:8000)}}` | обязателен, только http/https |
| height   | `{{web_window(http://адрес, height=600)}}` | высота окна в пикселях, 100–3000, по умолчанию 485; значения вне диапазона заменяются на 485 |

Окон может быть несколько: либо несколько блоков «Текст», либо несколько
макросов в одном блоке (каждый на своей строке).

## Если адрес не показывается

- адрес должен начинаться с `http://` или `https://` — иначе вместо окна
  будет подсказка;
- страница должна быть доступна с компьютера пользователя (адрес проверяется
  в его браузере);
- если страница имеет собственный вход — в окне спросит логин/пароль этой
  страницы (отдельно от Redmine);
- если страница отдаёт заголовок `X-Frame-Options` (например, SAMEORIGIN или
  DENY) — браузер покажет пустое окно: такую страницу встроить нельзя, это
  ограничение самой страницы, а не плагина.

## Примечания

- Если в additionals уже есть похожий макрос `{{iframe}}` — можно
  пользоваться им; наш макрос называется иначе и не конфликтует.
- Удаление: убрать папку из `plugins/` и перезапустить Redmine; после этого
  макросы `{{web_window}}` останутся в тексте как обычный текст — блоки
  «Текст» с ними можно просто очистить.
